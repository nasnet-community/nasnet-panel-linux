- In router mode a node with a domestic address is reached over the Domestic link, and falls back to the VPN only if that fails. Before, every node was dialled through the VPN, so a domestic node took the long way round, and every directly reached node went dark whenever no VPN tunnel was up.
- Resetting the admin password from `sudo nasnet` takes effect. It used to write a place the panel no longer reads, so once the password had been changed in the panel a reset did nothing, even after a restart. It also works without `htpasswd`.
- Taking a tunnel down and up no longer shows as a burst of traffic on the dashboard.
- Node agents are version 1.3.0. Releases also carry gzipped agents, about a third of the size, for slow links; a node unpacks one and checks the signed binary inside.
- This release carries the agent that the Remote Nodes plugin for the MikroTik panel installs on its nodes. The plugin ships as an image of its own.

Upgrading from v1.2.0: update from Settings → Updates, then update each node's agent from the Nodes page.
