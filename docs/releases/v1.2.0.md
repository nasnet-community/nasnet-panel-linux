- The panel updates itself from Settings → Updates. It looks for a release every 6 hours and installs when you click Update, now or at a time you pick. A new version has 2 minutes to come up healthy, or the old one is put back on its own; Roll back stays open for 7 days. A server that can't reach GitHub takes the offline bundle as an upload, or gets releases through the outbound proxy or a mirror.
- Releases are signed. Panels and node agents refuse a release, bundle or agent the release key didn't sign, and `nasnet` checks it too where OpenSSL 3 is installed.
- Every install runs the panel as root, so router changes and SSH settings work after a `sudo` install.
- Every node runs Xray 26.10.21. XTLS withdrew 26.10.10 over root certificates it still trusted, so update each node's Xray from the Nodes page. The built-in node runs Xray from the panel's own copy and moves with panel updates, unless you pick another version in its Xray dialog.
- `nasnet` Auto-Update runs the same updater as Settings, and the `nasnet` command now comes from the release instead of the latest code.
- Restart in Settings waits for the new process before it reloads the page.

Upgrading from v1.0.0: it has no updater of its own yet, so run `sudo nasnet` and pick Auto-Update. Then run `sudo nasnet` once more and accept switching the panel to root; after that, updates install from Settings → Updates. Update each node's agent and Xray from the Nodes page. Docker installs: `git pull && docker compose up -d --build`.
