# شروع به کار — نصب پنل NasNet

[🇬🇧 English](./getting-started.md) · **🇮🇷 فارسی**

<div dir="rtl" align="right">

یک راهنمای ساده و گام‌به‌گام برای اجرای پنل NasNet روی سرور شما. در پایان، پنل را در مرورگر باز می‌کنید و به‌عنوان مدیر وارد می‌شوید.

**یکی** از دو مسیر زیر را انتخاب کنید. اگر مطمئن نیستید، از **گزینهٔ الف** استفاده کنید.

---

## پیش از شروع

نیاز دارید به:

- ✅ یک **سرور Linux ۶۴ بیتی** (`amd64` یا `arm64`) — مثلاً یک VPS تازهٔ Ubuntu/Debian.
- ✅ دسترسی **root یا `sudo`** روی آن سرور (از طریق SSH وارد شوید).
- ✅ یا یک **نام دامنه** که به سرور اشاره کند (توصیه‌شده — HTTPS خودکار را فعال می‌کند) **یا** فقط **آدرس IP** سرور (روی HTTP ساده کار می‌کند).
- ✅ یک پورت آزاد برای پنل — پیش‌فرض **`9761`** (آن را در فایروال / پنل ارائه‌دهنده باز کنید).

همین. نصب‌کننده خودش Docker، پایگاه داده و تمام رمزها را برایتان مدیریت می‌کند.

---

## گزینهٔ الف — نصب‌کنندهٔ راهنما (ساده‌ترین) ⭐

یک اسکریپت چند سؤال می‌پرسد و همه‌چیز را انجام می‌دهد: اگر Docker نبود نصبش می‌کند، تمام رمزها و رمز عبور مدیر شما را می‌سازد، پیکربندی را می‌نویسد و پنل را راه‌اندازی می‌کند.

```bash
# ۱. دانلود پروژه
git clone https://github.com/nasnet-community/nasnet-panel-linux.git
cd nasnet-panel-linux

# ۲. اجرای نصب‌کننده (با sudo — ممکن است Docker نصب و سرویس‌ها را تنظیم کند)
sudo ./nasnet-tool.sh
```

ویزارد از شما می‌پرسد:

1. **سرور چطور در دسترس است؟** — **آدرس IP** یا **نام دامنه** را انتخاب کنید.
2. **نام کاربری و رمز عبور مدیر** — شما آن‌ها را وارد می‌کنید؛ ابزار خودش رمز عبور را هش می‌کند.
3. **پروکسی معکوس؟** — اگر همین حالا nginx/Caddy برای TLS اجرا نمی‌کنید، **خیر** را بزنید.

سپس همه‌چیز را نصب و پنل را راه‌اندازی می‌کند. وقتی تمام شد، **آدرس پنل** شما را چاپ می‌کند — بازش کنید و وارد شوید. تمام. ✅

> بعداً هر وقت خواستید دوباره `sudo ./nasnet-tool.sh` را اجرا کنید تا از همان منو **به‌روزرسانی**، **پشتیبان‌گیری / بازیابی**، **پیکربندی مجدد** یا **حذف نصب** کنید.

## گزینهٔ ب — Docker Compose (دستی)

اگر از قبل **Docker** + افزونهٔ **Docker Compose** را دارید و ترجیح می‌دهید خودتان پیکربندی را ویرایش کنید، این را انتخاب کنید.

```bash
# ۱. دانلود پروژه
git clone https://github.com/nasnet-community/nasnet-panel-linux.git
cd nasnet-panel-linux

# ۲. ساخت فایل پیکربندی
cp .env.example .env
```

**۳. دو رمز بسازید.** این‌ها را اجرا و نتیجهٔ هرکدام را کپی کنید:

```bash
# رمز JWT (در JWT_SECRET_KEY قرار می‌گیرد)
openssl rand -hex 32

# هش رمز عبور مدیر (در ADMIN_PASSWORD_HASH قرار می‌گیرد)
htpasswd -nbBC 10 "" "your-password" | tr -d ':\n' | sed 's/$2y/$2a/'
```

**۴. `.env` را ویرایش کنید** و دست‌کم این پنج مقدار را تنظیم کنید:

| کلید | مقدار |
|------|-------|
| `ADMIN_USERNAME` | نام کاربری ورودی که می‌خواهید |
| `ADMIN_PASSWORD_HASH` | هش حاصل از گام ۳ |
| `JWT_SECRET_KEY` | رشتهٔ تصادفی حاصل از گام ۳ |
| `APP_BASE_URL` | `https://your-domain` **یا** `http://your-ip:9761` |
| `DB_PASSWORD` | یک رمز عبور قوی برای پایگاه داده |

**۵. راه‌اندازی:**

```bash
docker compose up -d
docker compose logs -f app     # مشاهدهٔ راه‌اندازی؛ برای توقف مشاهده Ctrl+C
```

وقتی لاگ نشان داد برنامه آماده است، `APP_BASE_URL` خود را باز کنید و وارد شوید. ✅

<details>
<summary><b>SQLite را ترجیح می‌دهید (بدون پایگاه دادهٔ جداگانه)؟</b></summary>

برای یک راه‌اندازی کوچک می‌توانید PostgreSQL را کنار بگذارید. در `.env` تنظیم کنید:

```dotenv
DB_DRIVER=sqlite
DB_PATH=/app/data/nasnet_panel.db
```

سپس با فایل override مربوط به SQLite راه‌اندازی کنید:

```bash
docker compose -f docker-compose.yml -f docker-compose.sqlite.yml up -d
```
</details>

## اولین ورود

1. آدرس پنل خود را باز کنید (از نصب‌کننده، یا `APP_BASE_URL` شما).
2. با **نام کاربری مدیر** و **رمز عبور** خود وارد شوید.
3. وارد شدید! حالا پروکسی خود را راه بیندازید و اشتراک‌ها را توزیع کنید:
   - [سرور و Xray](./nodes-and-agents.md) — هستهٔ پروکسی را روشن و اینباوند اضافه کنید.
   - [اشتراک‌ها و کلاینت‌ها](./subscriptions-and-clients.md) — کاربر بسازید و لینک‌ها را به اشتراک بگذارید.

## نگه‌داشتن در حال اجرا

- **به‌روزرسانی:** `sudo ./nasnet-tool.sh` ← **Update**، یا (Docker) ‏`git pull && docker compose up -d --build`.
- **اول پشتیبان بگیرید** — مهاجرت‌های اسکیما هنگام به‌روزرسانی به‌طور خودکار اجرا می‌شوند. [پشتیبان‌گیری و بازیابی](./backup-and-restore.md) را ببینید.
- **حذف نصب:** `sudo ./nasnet-tool.sh` ← **Uninstall**، یا (Docker) ‏`docker compose down` (‏`-v` داده‌ها را هم حذف می‌کند — مخرب).

- [عیب‌یابی و پرسش‌های متداول](./troubleshooting-and-faq.md) را ببینید.
